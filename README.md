# Tony

A Claude-powered "capo" for a Minecraft (Paper) server. Players type `@tony` in chat, and Tony answers in an Italian-American mafia voice, then actually does things: teleports, weather and time, gives, summons, potion effects, finding a player's bed or death spot. The server owner ("the Don") gets extra powers, including running arbitrary server commands through Tony.

## How it works

- `index.js` tails the server's `logs/latest.log`, keeps a short chat history and online roster, and sends each `@tony` message to Claude (Haiku 5.5) with the persona in `prompt.js` and the tools in `tools.js`.
- Every tool call is checked again in code before it runs. Owner-only tools, item/mob/effect allow-lists, cooldowns and per-hour limits don't depend on the model behaving.
- Commands reach the server through the console's `screen` session, or over RCON when the reply matters (bulk gives, owner commands). The RCON password is read from `server.properties` at runtime.
- `gamedata/` holds the item, mob and effect lists for the server's Minecraft version, generated by `gamedata/build.js` from the vanilla server's own data reports, so every ID is real.
- `give.js` packs large owner gives into shulker boxes.
- `plugin-source/` is TonyBcast, a small Paper plugin for Tony's colored chat lines and for counting mobs near a player.

## Setup

1. Node 18+, plus `screen`, `tail` and `prlimit` on the server host.
2. Run the Paper server inside a `screen` session and enable RCON in `server.properties`.
3. Build TonyBcast against the Paper API for your server version and put the jar in `plugins/`.
4. `npm install`, then copy `.env.example` to `.env` and set `ANTHROPIC_API_KEY`.
5. Edit the `SERVERS` map at the top of `index.js` (server directory, screen session name, address) and set `OWNER` to your Minecraft username.
6. `TONY_SERVER=<name> node index.js` (one process per server).

## Security notes

- Owner powers are granted by the chat name in the server log, so this is only safe with `online-mode=true`. On Geyser/Floodgate servers, keep Floodgate's username prefix (the default `.`) so a Bedrock player can't take the owner's name.
- `mc_command` blocks commands that take the server down or hand out power (`stop`, `op`, `ban`, `whitelist`, `datapack`...), also after `execute ... run`. Review the list before giving Tony to anyone else.
